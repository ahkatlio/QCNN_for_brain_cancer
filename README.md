# Brain Tumor Dataset

## Overview of the Dataset

This dataset contains 3064 T1-weighted contrast-enhanced images from 233 patients with three types of brain tumors: meningioma (708 slices), glioma (1426 slices), and pituitary tumor (930 slices). The data is organized in Matlab data format (.mat files), with each file storing a struct that contains various fields describing the image and tumor information.

## Dataset Structure

Each Matlab (.mat) file in the dataset contains the following fields:

- **cjdata.label:** An integer value representing the type of tumor. It is coded as follows:
  - 1: Meningioma
  - 2: Glioma
  - 3: Pituitary Tumor

- **cjdata.PID:** Patient ID, a unique identifier for each patient.

- **cjdata.image:** Image data representing the brain scan.

- **cjdata.tumorBorder:** A vector that stores the coordinates of discrete points on the tumor border. The vector format is as follows:
  - [x1, y1, x2, y2, ...] 
  - The pairs x1, y1, x2, y2, etc., represent planar coordinates on the tumor border. These coordinates were generated by manually delineating the tumor border and can be used to generate a binary image of the tumor mask.

- **cjdata.tumorMask:** A binary image where pixels with a value of 1 indicate the tumor region.
